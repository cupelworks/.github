We make AI testing tools for quality engineering teams. An LLM app answers differently every run, so one passing test proves little; our tools turn runs into evidence: tests you can repeat, scores you can compare, verdicts your QE team can sign off on.

## What you'll find here

**Assay** is the first CupelWorks product: a Python framework that tests LLM-powered applications the way your QE team tests everything else. You give it datasets of prompts, model outputs and expected outputs; it scores every output and gives a verdict. Run a test once, or as many times as you decide: with repeated runs, the verdict rests on the distribution of scores rather than on a single answer. Tests sit in suites and plans, as in the test management tools your team already uses.

The Assay core is open source under AGPL-3.0-only: [cupelworks/assay](https://github.com/cupelworks/assay).

## Working in the open

Our code is public: read it, run it, host it. Issues are welcome: report a bug or ask for something, and we fix it ourselves, in our own way. We don't take pull requests, and we don't use code posted in issues either. Report a security vulnerability privately through the repository's Security tab.
